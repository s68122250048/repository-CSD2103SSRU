วิธีการทดลอง

ในการทดลองนี้เลือกอัลกอริทึมจาก 2 หัวข้อ ได้แก่

ข้อ 1: การกลับสตริง (Recursive และ Iterative)
ข้อ 2: การตรวจสอบ Palindrome (Reverse & Compare และ Recursive Two-Pointer)

กำหนดขนาดข้อมูล 4 ระดับ คือ
n = 100, 1,000, 10,000 และ 100,000

ใช้คำสั่งในการวัดเวลา ดังนี้

long start = System.nanoTime();

// เรียกใช้อัลกอริทึม

long end = System.nanoTime();
System.out.println("Execution time: " + (end - start) + " nanoseconds");

ในแต่ละขนาดข้อมูล ทำการทดลองอย่างน้อย 5 ครั้ง แล้วนำเวลาที่ได้มาคำนวณค่าเฉลี่ย

Average Time = ผลรวมเวลาทั้งหมด ÷ จำนวนครั้งที่ทดลอง

การวิเคราะห์ผลการทดลอง

1.ผลการทดลองสอดคล้องกับ Big-O ที่วิเคราะห์ไว้หรือไม่
 ผลที่ได้สอดคล้องกับการวิเคราะห์เชิงทฤษฎี โดยอัลกอริทึม Recursive ในการกลับสตริงมีแนวโน้มเวลาเพิ่มขึ้นแบบ O(n²) ขณะที่ Iterative เป็น O(n) ส่วนอัลกอริทึมตรวจสอบ Palindrome ทั้งสองแบบมีความซับซ้อน O(n) แต่มีพฤติกรรมต่างกันในทางปฏิบัติ
2.อัลกอริทึมใดเร็วที่สุดเมื่อข้อมูลมีขนาดเล็ก
 เมื่อ n มีขนาดเล็ก อัลกอริทึมทุกแบบให้เวลาใกล้เคียงกัน แต่ Iterative และ Recursive Two-Pointer จะมีแนวโน้มเร็วกว่าเล็กน้อย
3.อัลกอริทึมใดเหมาะสมที่สุดเมื่อข้อมูลมีขนาดใหญ่
 สำหรับการกลับสตริง วิธี Iterative เหมาะสมที่สุด เนื่องจากทำงานเร็วและไม่ใช้หน่วยความจำเพิ่มมาก
 สำหรับการตรวจสอบ Palindrome วิธี Recursive Two-Pointer เหมาะสมกว่าในบางกรณี เนื่องจากสามารถหยุดการทำงานได้เร็วหากพบความไม่ตรงกันตั้งแต่ต้น
4.Recursive Algorithm มีข้อจำกัดด้านหน่วยความจำอย่างไร
 การเรียกซ้ำจะใช้พื้นที่ใน Call Stack ตามจำนวนครั้งที่เรียก ทำให้เมื่อข้อมูลมีขนาดใหญ่ อาจเกิดปัญหา Stack Overflow และใช้หน่วยความจำมากกว่าวิธี Iterative
5.เหตุใดอัลกอริทึมที่มี Big-O เท่ากันจึงอาจใช้เวลาจริงแตกต่างกัน
 แม้จะมีความซับซ้อนเชิงเวลาเท่ากัน แต่เวลาจริงอาจต่างกันเนื่องจากค่าคงที่ในการคำนวณ (constant factor) การจัดการหน่วยความจำ การสร้างอ็อบเจ็กต์ใหม่ และลักษณะการทำงาน เช่น การมี Early Exit
6.การวัดเวลาเพียงครั้งเดียวเพียงพอหรือไม่ เพราะเหตุใด
 การวัดเพียงครั้งเดียวไม่เพียงพอ เนื่องจากอาจได้รับผลกระทบจากปัจจัยภายนอก เช่น การทำงานของระบบปฏิบัติการ การจัดการหน่วยความจำ หรือ JIT Compiler ดังนั้นควรวัดหลายครั้งแล้วหาค่าเฉลี่ยเพื่อให้ได้ผลลัพธ์ที่น่าเชื่อถือ
